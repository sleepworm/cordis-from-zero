# v0.1.1 — 两个问候实现，运行时切换语言

## 代码

`vanilla/index.ts`：一个 `Greeter` 接口，两个实现（英文、中文），一个变量指向"当前用哪个"。

```ts
interface Greeter {
  greet(name: string): string
}

const englishGreeter: Greeter = {
  greet: (name) => `Hello, ${name}!`,
}

const chineseGreeter: Greeter = {
  greet: (name) => `你好，${name}！`,
}

let greeter: Greeter = englishGreeter

function app() {
  console.log('[App]', greeter.greet('Alex'))
}

app()

greeter = chineseGreeter
app()
```

切换语言就是给 `greeter` 重新赋值，再调用一次 `app()`。

## 怎么跑

```bash
npm install
npm run demo:vanilla
```

## 结果

```
[App] Hello, Alex!
[App] 你好，Alex！
```

## 这一步的定位

故意不引入任何框架，也故意不制造痛点——这是诚实的起点：这么小的需求，一个变量就够了，没有理由用别的东西。后面几步会不断加需求，直到这种写法开始不够用为止。
